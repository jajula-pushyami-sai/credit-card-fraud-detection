2. Root Cause Analysis & Machine Learning Resolution

The primary operational failure in the initial codebase was that backend/app/ml/inference/predict.py threw a 503 ModelNotReadyError on every prediction or transaction creation request.

The Root Problem

  • Missing Production Artifacts: The inference service required 4 core artifacts (scaler.pkl, extra_trees.pkl, mlp.keras, xgboost_meta.pkl) and schema.json inside backend/app/ml/models/saved/. None existed in the cloned repository because app/ml/models/ was mistakenly gitignored upstream.
  • Missing Raw Training Data: backend/app/ml/data/raw/creditcard.csv was missing from the repository, preventing local retraining.
  • TensorFlow & Python Dependency Incompatibilities: The MLP model required TensorFlow and Keras, which were uninstalled. Subsequent installation pulled NumPy 2.x, which caused binary ABI incompatibilities with compiled C-extensions in SHAP (_ARRAY_API not found).

Remediation Steps Taken

  1. Dataset Acquisition: Downloaded the full 143.84 MB Kaggle/HuggingFace credit card dataset (284,807 rows & 30 canonical features) to backend/app/ml/data/raw/creditcard.csv.
  2. Engineered Machine Learning Toolchain: Installed TensorFlow 2.21 and Keras 3.15. Pinned numpy==1.26.4 to ensure seamless C-extension compatibility across TensorFlow, Scikit-learn, XGBoost, LightGBM, and SHAP.
  3. Fixed Training Pipeline Bugs:
    • backend/app/ml/training/mlp.py: Corrected a bug where epochs=500 was hardcoded, ignoring the caller's parameter.
    • backend/app/ml/training/extra_trees.py: Enabled configurable n_estimators=100 to prevent memory bloat and long training timeouts on resampled data.
  4. Full Model Training Execution: Executed train_models.py with stratified 80/20 train/validation split, StandardScaler, and SMOTE resampling. Generated and verified all 6 artifacts:
    Artifact File Size Role
    Feature Schema schema.json 380 B Canonical 30-feature schema enforcement
    Feature Scaler scaler.pkl 1.7 KB Fitted StandardScaler on training fold
    Base Model 1 extra_trees.pkl 56.8 MB Randomized decision trees for non-linear interactions
    Base Model 2 mlp.keras 238 KB Swish-activated Deep MLP Neural Network
    Meta Learner xgboost_meta.pkl 15.4 KB Gradient boosted stacking aggregator
    Validation Metrics eval_metrics.json 341 B ROC-AUC: 0.9480, Precision: 1.0000, F1: 0.4444
  5. Fixed SHAP Explainability Engine: In backend/app/ml/explainability/engine.py, patched explain_local_shap() to reliably extract 1D positive-class SHAP contribution arrays across both list and 3D ndarray formats returned by SHAP 0.45.0.
